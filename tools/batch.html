圖片批次轉換

人物、怪物的三視圖 → 遊戲用走路動畫；場景圖 → 像素風

請用「圖片批次轉換」程式開啟

現在是直接打開網頁檔，讀不到你電腦裡的資料夾，所以「打開原圖資料夾」、「重新掃描」、「開始批次轉換」都不能用（步驟 2 的預覽用「從電腦選圖」還是可以試）。請這樣開啟：

  1. 關閉這個分頁。
  2. 雙擊桌面上的「圖片批次轉換」捷徑，或遊戲資料夾 D:\RPG 裡的 圖片批次轉換.exe。

1選擇資料夾，把圖放進去

原圖資料夾 （還沒選）
放人物、怪物、場景原圖的地方。可以選任何位置（例如雲端硬碟裡的資料夾），換電腦時選一次就好。轉換設定也會存在這裡面（batch-settings.json）。
輸出資料夾 （還沒選）
轉好的圖存在這裡。選「自動」時：原圖資料夾旁邊有遊戲的 assets 資料夾，就存到 assets\custom；沒有的話存到原圖資料夾旁邊的「轉換結果」。

選好原圖資料夾後，裡面會自動建立 characters、monsters、scenes 三個資料夾。按「打開」照這個方式放圖：

原圖資料夾\ ├─ characters\ ← 人物：每個角色開一個資料夾 │ ├─ knight\ ← 資料夾名稱 = 轉好之後的檔名，請用英文 │ │ front.png side.png back.png ← 三張分開的圖 │ └─ mage\ │ sheet.png ← 或是一張「三視圖」（三個角度畫在同一張） ├─ monsters\ ← 怪物：放法跟人物一樣 │ └─ slime\ │ front.png ← 怪物只有正面也可以，其他方向會用正面代替 └─ scenes\ ← 場景：圖直接放進來，不用開資料夾 forest.png town.png

放圖的規則：

  • 三張分開的圖：檔名要包含 front（正面）、side（側面）、back（背面），例如 knight_front.png。用中文「正面、側面、背面」也可以。
  • 一張三視圖：資料夾裡只放這一張就好（檔名不限）。三個角度要由左到右排好、中間留空隙，排列順序在步驟 2 設定。
  • 背景：用透明背景或單一純色（例如全白）。背景有漸層、陰影或花紋會去不乾淨。
  • 側面圖：所有角色的側面要朝同一邊（都朝左或都朝右），在步驟 2 設定。
  • 可以放 PNG、JPG、WebP。圖越大越清楚，但每張最好不要超過 2000 像素寬。
  • （選用）也可以加跨步圖 front_step.png、side_step.png、back_step.png，走路動畫會更自然。
放好之後回到這個視窗，繼續步驟 2。

2選擇轉換設定

這裡的設定是每一類的預設值，會套用到同一類的所有圖片，下次打開會記住。
右邊選一張範例圖（從原圖資料夾選，或按「從電腦選圖」、把圖拖進預覽框），調整左邊的設定時，右邊會立刻顯示轉出來的樣子。調到滿意就好，不用存檔。

進階：個別角色用不同設定

在角色資料夾裡放一個 settings.json，只寫要改的項目，其他照上面的設定。場景則是放一個跟圖同名的 json，例如 forest.json。例如某隻大型怪物要 32×32、側面朝右：

{ "w": 32, "h": 32, "sideFacing": "right" }

人物、怪物可以用的項目：w、h（每格大小）、dirCount（"4" 或 "8"）、sideFacing（"left" 或 "right"）、sheetOrder（例如 "front,side,back"）、colors、palette（"game"、"auto"…）、outline（"outer"、"inner"、"none"）、bgMode（"auto"、"manual"、"off"）、bgManual（例如 "#ffffff"）、bgTol、legRatio（腳的長度 %）、lift、bob、stride。
場景可以用的項目：outW（輸出寬度）、scale、sizeBy（"width" 或 "scale"）、colors、palette、dither（"none"、"bayer"、"fs"）。

3檢查找到的圖

按「重新掃描」讀取資料夾。確認每一列的判斷都正確；有 ⚠ 的那列要先照提示修正（改檔名或補圖），再按一次重新掃描。不想轉換的，把前面的勾勾取消。

4開始轉換

按下開始後，會一個一個轉換，轉好的圖存進步驟 1 的輸出資料夾 （還沒選）：

  • 人物：輸出資料夾\characters\角色名\Walk.png（走路動畫）和 Idle.png（站姿）
  • 怪物：輸出資料夾\monsters\怪物名\Walk.png 和 Idle.png
  • 場景：輸出資料夾\scenes\場景名.png

同名的舊檔會被覆蓋。轉換時可以先看下面的結果，不滿意就回步驟 2 調整，再轉一次。
