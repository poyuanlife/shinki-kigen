# 神機紀元 · 青葉之原（測試版）

和風忍者打寶動作 RPG，直接在瀏覽器裡玩，電腦和手機都可以。

**遊玩網址：https://poyuanlife.github.io/shinki-kigen/**

## 手機操作（建議橫向）

| 操作 | 功能 |
|---|---|
| 左下搖桿 | 移動 |
| 按住「攻擊」 | 自動攻擊最近的敵人 |
| 技能鍵 | 對最近的敵人施放已學會的技能 |
| 點怪物 / 道具 / NPC | 攻擊 / 撿起 / 對話 |
| 點背包裡的道具 | 顯示說明與「裝備、出售、丟棄」按鈕 |

用瀏覽器選單的「加到主畫面」，就能像 App 一樣全螢幕開啟。

## 電腦操作

| 按鍵 | 功能 |
|---|---|
| WASD / 方向鍵 | 移動 |
| 空白鍵（按住） | 自動攻擊最近的敵人 |
| 左鍵 | 移動 / 攻擊 / 拾取 |
| Shift + 左鍵 | 原地投擲 |
| 右鍵 | 施放選定的技能 |
| 1～8 | 快捷技能 |
| Q | 生命藥水 |
| E | 魔力藥水 |
| C / I / K | 角色 / 背包 / 技能樹 |
| T | 回營地 |
| Tab | 小地圖 |
| Esc | 系統選單（音量、畫質、存檔、離開） |
| N / V | 音樂 / 音效開關 |
| F2 | 診斷報告（遇到問題時複製給開發者） |

存檔存在你自己的瀏覽器裡；換電腦或清除瀏覽器資料後進度不會保留。

## 在自己電腦上執行

雙擊 `開始遊戲.bat`（需要安裝 [Node.js](https://nodejs.org/)），或直接打開 `index.html`。
